# Tensura Reborn

A Fabric mod for Minecraft 26.1.2 inspired by *That Time I Got Reincarnated as a Slime*. Be reborn as a monster
or a human, grow from humble beginnings, and rise to face the strongest beings of a world full of magic.

- Reincarnate as one of many races, and evolve as you grow stronger.
- Earn and master skills, from simple magic up to unique and ultimate skills.
- Name monsters to raise them up, and gather a following of your own.
- Journey to other worlds and face fearsome bosses, each fighting in its own way.
- Anime-inspired skill effects, and an in-game Codex that explains it all.

**Made with AI.** This mod was developed with the use of AI.

If you are against AI-made work, please don't play it. This mod is heavily based on *Tensura: Reincarnated*;
if you want to support the people who make this kind of mod by hand, go play and support [*Tensura: Reincarnated*](https://www.curseforge.com/minecraft/mc-mods/tensura-reincarnated)
and its creators, ManasMods.

## Before you play

**Play at your own risk.** Tensura Reborn is built and tested for singleplayer. Multiplayer isn't supported yet,
and it hasn't been tested with other mods: running it alongside other popular mods may cause crashes or odd
behaviour. Back up your worlds.

Tensura Reborn is a personal project. Updates and long-term support aren't guaranteed.

## Requirements

- Minecraft: Java Edition 26.1.2
- Fabric Loader for 26.1.2
- Java 25 (the Minecraft launcher includes it)

Fabric API is already inside the jar; you don't need to install it.

## Install

Download the JAR from the [0.2.2 release](https://github.com/SlimeQube/tensura-reborn/releases/tag/v0.2.2).

1. Install Fabric Loader for Minecraft 26.1.2 from [fabricmc.net](https://fabricmc.net/use/installer/).
2. Put `tensura-reborn-0.2.2.jar` in your `.minecraft/mods` folder.
3. Start Minecraft with the Fabric profile.
